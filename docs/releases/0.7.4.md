# Claude Usage Desktop 0.7.4

This release publishes the full current desktop version, including previously
unreleased features, as approved by the owner on 1 November 2026.

## Graphs and history

- Usage chart gridlines now use equal, round-number intervals. Labels and plotted
  values share the same scale; observed totals are not rounded to those intervals.
- Shared Claude/Codex Stats navigation supports 1-, 7- and 30-day periods, previous
  and next periods, and returning to the latest observations.
- Codex quota history starts with recorded observations; gaps and resets are not
  presented as complete consumption. History remains separated by account.
- Codex credit spending includes today and the preceding six UTC dates. Today's
  total is spending so far, not a projected complete day.

## Other included changes

- Codex credit runway estimates and saved, rearrangeable dashboard cards.
- Compact provider-status disclosures, clearer access-error explanations and
  acknowledged cached status refresh without forcing additional provider calls.
- More resilient local/optional relay source recovery and relay startup handling.
- An optional OpenRouter account-spend card and bounded exporter/sync tools. This
  remains opt-in; publishing the release does not configure credentials or tasks.
- The portable ZIP and installer include the OpenRouter exporter/sync helper
  scripts alongside the relay startup helper. Installation does not run them.

## Updating and verification limits

The installer upgrades program files in place and preserves existing application
settings and usage history. Close the running app before installing the update.
The portable ZIP and Windows installer are built from the same version-checked
payload. Release preparation does not restart or install the app automatically.

No new data-handling or policy wording is introduced by this release operation.
The existing technical inventory is in `docs/data-handling.json`.
