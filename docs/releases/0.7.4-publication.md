## Verification

* Release-configuration .NET tests: 210 passed, no failures or skips.
* Full JavaScript suite after the packaging correction: 40 passed.
* Exporter and mocked Windows sync integration tests: 21 passed. These ran with
  the documented timezone-data dependency in an isolated Python environment;
  live exporter credentials and scheduled tasks were not configured.
* Version gate, ZIP packaging, NSIS payload gate, installer build, release upload
  and post-publication checks all passed.

The first packaging attempt was stopped before tagging or publication when its
missing OpenRouter helpers were found. The project and installer were corrected,
regression tests added and all artifacts rebuilt before this single release was
published. No broken 0.7.4 release was published or replaced.

The release used:

```text
release.ps1 0.7.4 -NotesFile docs/releases/0.7.4.md -NoRelaunch
```

The running app was not stopped, restarted or installed. Installer UI, interactive
graphs and upgrade behavior were not visually tested during this operation.
Users should close the app before installing the update, then check their saved
settings/history and graph labels. The optional sync/export helpers remain
unconfigured and opt-in.

## Dependent systems

The DabbleLabs homepage and project page already link to this repository's
`releases/latest`, so the new downloads require no site deployment or asset edits.
The Android rounded-axis helper is separately merged into the shared library's
`main` at `1c556ab`; WeedModerator 1.2.2/code 8 is published on Play Internal
Testing, with its receipt in that app's `docs/releases/1.2.2.md`. SleepTracker's
existing round hour/percentage axes were unchanged, so no SleepTracker release
was needed for this work.
